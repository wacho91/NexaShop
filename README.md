🛒 NexaShop - Plataforma E-commerce B2C
NexaShop es una plataforma de comercio electrónico moderna y completa, diseñada con una arquitectura de software desacoplada (Headless). Ofrece una experiencia de usuario fluida y premium tanto para los clientes finales como para los administradores de la tienda.

🚀 Características Principales
Tienda Pública Premium: Landing page con carrusel de imágenes dinámico, categorías visuales, sección de testimonios y captación de clientes (Newsletter).
Galería de Productos: Vista de detalle con miniaturas interactivas, selector de cantidad y validación de stock en tiempo real.
Carrito de Compras Persistente: Gestión de carrito para usuarios invitados y registrados, con cálculo automático de subtotales y envíos.
Checkout Funcional: Procesamiento de órdenes con descuento automático de inventario (Kardex) al finalizar la compra.

Panel de Administración (Dashboard): Métricas de ventas (diarias, semanales) con gráficos interactivos, gestión CRUD de productos, categorías y gestión de órdenes.
Experiencia de Usuario (UX) de Nivel Dios:
Modo Claro/Oscuro dinámico.
Notificaciones "Toast" al agregar productos al carrito.
Animación "Bump" en el ícono del carrito.
"Skeleton Loading" (Carga fantasma) para transiciones ultrarrápidas.
Diseño 100% Responsive (Móvil, Tablet, Escritorio).

🛠️ Stack Tecnológico
Backend: Python, FastAPI (Arquitectura Asíncrona), SQLAlchemy, JWT (Autenticación y Roles RBAC), SQLite ( listo para migrar a PostgreSQL).
Frontend: React, Vite, Tailwind CSS, React Router, Recharts (Gráficos), React Hot Toast, Context API.
Arquitectura: REST API desacoplada (Headless Commerce), lista para consumirse desde cualquier frontend o app móvil futura.
